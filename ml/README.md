# Machine Learning (ML) Pipeline & Model Governance

This directory contains datasets, preprocessing scripts, model training routines, and evaluation metrics for the complaint classification, sentiment analysis, and vector embedding models.

## Directory Structure
- `datasets/raw/`: Raw customer complaint feeds, tickets, and legacy logs.
- `datasets/processed/`: Normalized, tokenized, and labeled datasets for training.
- `preprocessing/`: Feature extraction and text preprocessing pipelines.
- `training/`: Training scripts for Scikit-learn, PyTorch, and fine-tuning Hugging Face Transformers.
- `evaluation/`: Accuracy, precision, recall, F1 score, and confusion matrix evaluators.
- `models/`: Exported model weights, ONNX runtimes, and vectorizer checkpoints.
